# 모찌모찌 과일 찹쌀떡

```
      .-""""-.
    .'  ^  ^  '.
   (    ____    )    말랑말랑 쫀득쫀득
    '.  \__/  .'     오늘의 찹쌀떡은 내가 만든다
      '-....-'
```

반죽 한 덩이를 골라서 밀대로 쭉쭉 밀고, 팥이랑 과일을 올려서 꾹 감싼 다음, 칼로 쩍 갈라 단면을 보는 **과일 찹쌀떡 만들기 미니게임**이에요.
가르면 나오는 단면이 그대로 내 점수가 돼요. 예쁘게 만들수록 점수가 올라가요.

**바로 플레이하기:** https://jinisim.github.io/mochimochi/

설치할 건 없어요. 폰에서도 PC에서도 링크만 열면 바로 시작돼요.

---

## 만드는 순서

| 단계 | 할 일 | 이렇게 하면 좋아요 |
|---|---|---|
| 1. 피 고르기 | 도마 위 반죽 중 하나를 콕 눌러 접시로 데려와요 | 반죽마다 양이 조금씩 달라요. 너무 작으면 밀었을 때 얇아져요 |
| 2. 밀대로 밀기 | 밀대를 드래그해서 반죽을 넓게 펴요 | 한 방향으로만 밀면 길쭉해져요. 여러 방향으로 골고루 밀어 주세요. 너무 빠르게 밀면 울퉁불퉁해져요 |
| 3. 속 올리기 | 흔들리는 팥 앙금을 타이밍 맞춰 톡 떨어뜨리고, 과일도 똑같이 올려요 | 반죽 한가운데, 앙금 한가운데를 노려요 |
| 4. 감싸기 | 피 가장자리를 잡고 과일 쪽으로 쭈욱 당겨 덮어요 | 반죽이 한 덩어리로 끌려와요. 빙 돌아가며 골고루 덮고, 다 덮이면 **꾹 오므리기**! |
| 5. 반으로 자르기 | 칼을 들고 찹쌀떡을 가로질러 슥 그어요 | 한가운데를 지나갈수록 단면이 예뻐요 |
| 6. 단면 평가 | 흰 피, 팥, 과일이 보이는 단면과 함께 점수가 나와요 | "지니의 92점 찹쌀떡 완성!"처럼 내 닉네임으로 나와요 |

## 점수는 이렇게 매겨요 (100점 만점)

| 항목 | 배점 | 보는 것 |
|---|---|---|
| 밀기 | 20점 | 반죽 크기, 동그란 정도, 두께가 알맞은지 |
| 속 넣기 | 15점 | 팥과 과일이 가운데에 잘 올라갔는지 |
| 감싸기 | 45점 | 과일이 얼마나 덮였는지, 피 두께가 고른지 |
| 자르기 | 20점 | 칼이 찹쌀떡 한가운데를 지났는지 |

90점이 넘으면 **"완벽한 쫀득함!"** 칭호를 받아요.
점수가 아쉬우면 제일 부족했던 부분을 한 줄로 콕 집어 알려 줘요. "피가 울퉁불퉁해요", "속이 한쪽으로 쏠렸어요", "과일이 삐져나왔어요" 같은 식이에요.

## 고를 수 있는 과일

딸기, 샤인머스캣, 귤, 홍시가 있어요. 기본은 딸기예요.
주소 뒤에 `?fruit=` 를 붙이면 다른 과일로 시작해요.

- 샤인머스캣: `https://jinisim.github.io/mochimochi/?fruit=shine`
- 귤: `?fruit=tangerine`
- 홍시: `?fruit=persimmon`

## 작은 비밀들

- 소리도 직접 만들었어요. 밀 때 나는 "드르륵", 피가 늘어나는 "쭈욱", 붙을 때 "뽁", 자를 때 "쓱"은 전부 브라우저가 그 자리에서 합성해요. 소리 파일은 하나도 없어요.
- 과일과 찹쌀떡도 그림 파일 없이 캔버스에 직접 그려요.
- 게임 전체가 `index.html` 파일 하나에 다 들어 있어요.
- 닉네임은 이 브라우저에만 기억해 둬서 다음에 열면 미리 채워져 있어요.

## 만든 사람을 위한 메모

- **파일:** `index.html` 하나 (HTML, CSS, JS 전부 포함)
- **글꼴:** Google Fonts의 Jua(제목), Gowun Dodum(본문)
- **색:** 배경 `#FFFDFA`, 찹쌀 피 `#FFFFFF`, 글자와 테두리 `#3B2833`, 포인트 핑크 `#FF5C8A`(버튼, 점수, 게이지에만), 구분용 회색 `#F4F2F3`
- **과일 추가:** 코드 안 `FRUITS` 데이터에 이름, 크기, 색, 겉모습 그리기(`draw`), 단면 그리기(`section`)를 넣으면 돼요.
- **결과값:** 게임이 끝나면 `MochiGame.result`에 단계별 점수가 담긴 객체가 남고 `mochi:done` 이벤트도 나가요. 다음 단계를 붙일 때 이어받아 쓰면 돼요.
- **랭킹:** 닉네임 TOP10 랭킹 화면이 들어 있어요. 아직 저장소(Firebase)를 연결하지 않아서 이 페이지에서는 랭킹 버튼이 숨어 있어요.

## 업데이트하는 법

게임을 고쳤다면 새 `index.html`로 바꾼 뒤 아래처럼 올리면 같은 주소에 반영돼요. 1~2분 정도 걸려요.

```bash
git add index.html
git commit -m "찹쌀떡 업데이트"
git push
```
